# نظام إدارة المكتبة الشامل - Smart Library Management System

نظام إلكتروني إداري متكامل لتسهيل عمليات المكتبات الأكاديمية والجامعية، تم تطويره باستخدام **ASP.NET MVC** و **Entity Framework Core** مع قاعدة بيانات متكاملة بـ **SQL Server**.

## 🚀 الأقسام والمميزات الرئيسية (Modules & Features)
- **إدارة الكتب (Books Management):** تسجيل الكتب الجديدة، تصنيف الفئات، وتحديد الأسعار وتتبع المراجع.
- **إدارة عمليات الاستعارة (Borrowing Operations):** تسجيل إعارة الكتب للطلاب وتحديث حالة الإرجاع آلياً.
- **إدارة طاقم العمل (Staff Management):** تسجيل الموظفين، المسميات الوظيفية، وإدارة السجلات المالية والأجور.
- **إدارة الطلاب (Students Registration):** تسجيل وإدارة بيانات الطلاب والحرص على ربطها مع عمليات الإعارة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Backend:** C# / ASP.NET MVC
- **Database:** SQL Server / Entity Framework Core
- **Frontend:** HTML5, CSS3, Bootstrap (RTL Design)
